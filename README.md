# Online_Quiz_Website
This project presents a dynamic and interactive Online Quiz Website, built using HTML, CSS, and JavaScript. It provides users with an engaging platform to test their knowledge through a series of multiple-choice questions. The quiz features a timer, score tracking, and immediate feedback on answers, making educational experience.

The website includes a clear set of rules before starting the quiz, a question display area with options, a real-time countdown timer, and a final results screen showing the user's score. The design is clean and user-friendly, ensuring a smooth navigation and interaction flow. All components are responsive, adapting well to various screen sizes.
